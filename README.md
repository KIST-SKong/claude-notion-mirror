# Claude Notion Mirror

**claude.ai 안에서 내 Notion을 보고, 고치고, 가져오고, 내보내는 단일 HTML 앱입니다.**
서버 없이 `notion-mirror.html` 파일 하나로 되어 있고, claude.ai의 **아티팩트**로 게시해서 씁니다.

> *English summary:* A single-file app that runs as a claude.ai Artifact and lets you browse, edit, import and export your own Notion pages and databases through your own Notion connector in Claude. No server, no tokens in the file. Unofficial; not affiliated with Notion or Anthropic.

- 앱은 **여는 사람 본인의 Notion 연결**로 동작합니다. 같은 파일이라도 사람마다 자기 노트가 보입니다.
- 접속 정보나 토큰은 파일 어디에도 들어 있지 않습니다. 이 프로젝트가 데이터를 수집하거나 따로 저장하는 서버도 없습니다. Notion과의 통신은 claude.ai의 Notion 커넥터가 대신합니다.
- **claude.ai 안에서만 동작합니다.** 다른 웹 서버에 올리거나 HTML 파일을 그냥 열면 Notion에 연결되지 않습니다.
- Notion과 Anthropic(Claude)의 **공식 제품이 아니며**, 두 회사와 관련이 없는 개인 프로젝트입니다.

---

## 준비물

1. claude.ai 계정
2. claude.ai에 연결된 **Notion 커넥터** (설정 → 커넥터 → Notion → 내 워크스페이스에서 "액세스 허용")
3. 아티팩트를 게시할 수 있는 Claude (Claude Code, 데스크톱 앱의 Code 탭 등)

---

## 내 계정에 게시하기

1. 이 저장소에서 `notion-mirror.html`을 내려받습니다.
2. Claude Code에서 그 파일을 주고 아래처럼 요청합니다.

   > 이 파일을 아티팩트로 게시해줘. capabilities는
   > mcp: Notion 커넥터의 아래 도구 9개, downloads: true 로 해줘.
   >
   > `notion-list-private-pages`, `notion-list-recent-pages`, `notion-list-shared-pages`,
   > `notion-search`, `notion-fetch`, `notion-query-data-sources`,
   > `notion-create-pages`, `notion-update-page`, `notion-delete-pages`

3. 만들어진 링크를 열고, 처음 뜨는 **"Notion 접근 허용"** 창에서 허용을 누릅니다.
   파일 저장 허용 창은 내보내기를 처음 누를 때 한 번 뜹니다.

도구가 빠지면 그 기능만 동작하지 않습니다.

| 빠진 도구 | 안 되는 기능 |
|---|---|
| `notion-update-page` | 페이지·셀 편집 저장 |
| `notion-delete-pages` | 휴지통으로 옮기기 |
| `notion-list-shared-pages` | 공유 페이지 자동 목록 (검색 기반으로 대체) |
| `downloads` | Excel·CSV 내보내기 |

> **주의**: 이 앱은 Notion 내용을 **수정하고 휴지통으로 옮길 수 있는 권한**을 요청합니다. 처음에는 연습용 페이지나 데이터베이스에서 시험해 보세요. 삭제는 Notion 휴지통으로 이동하는 방식이라 복원할 수 있습니다.

## 할 수 있는 것

**왼쪽 목록**
- `고정됨` / `공유` / `개인` / `최근`. 공유·개인은 트리형이고 ▸로 하위 페이지를 펼칩니다.
- 페이지나 데이터베이스 위의 `☆ 고정`으로 자주 쓰는 것을 맨 위에 둡니다.
- 공유 목록의 `＋`로 공유받은 페이지를 이름으로 찾아 직접 등록하고, `⟳`로 새로고침합니다.

**페이지**
- 아무 줄이나 눌러 바로 편집합니다. Enter는 새 블록, `/`는 블록 종류 선택입니다.
- 제목·체크박스 편집, 하위 페이지 만들기가 됩니다.
- 입력을 멈추면 약 1초 뒤 자동 저장되고, 오른쪽 위에 저장 상태가 보입니다.
- `🗑 휴지통으로`는 확인을 거친 뒤 Notion 휴지통으로 옮깁니다.

**데이터베이스 (엑셀처럼 보이는 표)**
- 열 머리글을 눌러 정렬하고, 셀을 눌러 바로 편집합니다. 텍스트·숫자·선택·상태·다중 선택·날짜(시작/종료)·체크박스·관계형을 지원합니다.
  `Enter` 저장 / `Tab` 오른쪽 칸 / `Esc` 취소 / `Shift+Enter` 줄바꿈
- 관계형 셀은 연결된 페이지를 이름으로 보여 주고, 누르면 이동하며, 후보 목록에서 추가·해제합니다.
- **보기**: Notion에 저장된 보기를 고릅니다. 보기에 걸린 필터와 정렬이 그대로 적용됩니다.
- **열**: 처음에는 Notion 보기의 열 순서와 숨김을 따릅니다. 머리글을 끌거나 `▥ 열` 패널로 순서와 표시를 바꿀 수 있고, 되돌리기도 됩니다.
- **필터**: `▽ 필터`로 조건을 걸어 표와 내보내기에 반영합니다.
- 열 너비를 끌어서 조절하고(경계를 두 번 누르면 내용에 맞춤), `↵ 줄바꿈 켜기`로 긴 글을 모두 봅니다.
- 20행씩 보여 주고 `더 보기`, 행별 `🗑`로 휴지통 이동, 날짜 속성이 있으면 달력 보기도 됩니다.

**가져오기 / 내보내기**
- `⬇ 내보내기`: Excel(.xlsx) 또는 CSV. 화면에 보이는 열 순서와 필터·찾기·정렬 결과 전체를 저장합니다.
- `⬆ 가져오기`: Excel·CSV의 첫 줄을 열 이름으로 보고 속성에 연결합니다. 미리보기를 확인하고 `n행 가져오기`를 눌러야 새 행이 추가됩니다(기존 행은 바꾸지 않음).
  관계형 열은 **이름이 정확히 맞는 페이지**에 연결됩니다.

## 고쳐 쓰는 법

각자 입맛에 맞게 고쳐 쓰도록 만든 단일 파일입니다.

1. 위 방법으로 먼저 게시합니다. 이때 만들어진 링크(`https://claude.ai/artifact/...`)를 적어 둡니다.
2. 같은 Claude Code에서 고치고 싶은 점을 요청합니다.
   - "홈 화면 인사말을 바꿔줘"
   - "표에서 ○○ 열을 기본으로 숨겨줘"
   - "사이드바에 ○○ 섹션을 추가해줘"
3. 고친 파일을 **처음 게시한 링크에 이어서 올려 달라고** 요청하면 주소가 바뀌지 않습니다.
   새 대화에서는 이렇게 말하세요: "notion-mirror.html을 `<내 링크>`에 이어서 올려줘"
4. 링크를 잊어버렸다면 claude.ai/code/artifacts 갤러리에서 아티팩트를 열어 주소창에서 복사합니다.

**코드 구역** (`notion-mirror.html` 안의 주석 제목, Claude에게 "○○ 구역을 고쳐줘"라고 말하기 좋습니다)

| 주석 제목 | 내용 |
|---|---|
| `helpers` / `connector calls` | 공통 함수, Notion 호출과 오류 안내 문구 |
| `sidebar` | 왼쪽 목록, 트리, 고정, 공유 목록 |
| `move to trash` | 휴지통으로 옮기기와 확인 창 |
| `navigation` / `home` | 화면 이동, 홈 화면 |
| `page parsing` / `Notion-flavored markdown` | 페이지 내용 읽기와 화면 표시 |
| `page editor` / `slash menu` | 블록 편집, 자동 저장, `/` 메뉴 |
| `create pages` | 새 페이지 만들기 |
| `database rendering` | 데이터베이스 불러오기, 보기 선택, 툴바 |
| `column order and visibility` | 열 순서·표시 |
| `filters` | 필터 |
| `import / export` | Excel·CSV 가져오기와 내보내기 |
| `database table` | 표 그리기, 셀 편집, 열 너비 |
| `relation titles` / `relation editing` | 관계형 셀 표시와 편집 |

앱 안의 설정(고정, 열 순서, 열 너비, 필터 등)은 **각자의 브라우저에만** 저장되어서 서로 영향을 주지 않습니다.

## 자주 겪는 일

**표가 비어 있어요.**
보기에 Notion에서 건 필터(예: "최근 1주")가 있기 때문일 수 있습니다. 앱이 이유를 알려 주고, 필터 없는 보기로 바꾸는 버튼을 보여 줍니다. 위쪽 `보기` 선택칸에서 직접 바꿔도 됩니다.

**"데이터베이스 조회 한도를 다 썼어요"가 떠요.**
Notion 무료 요금제는 행 조회에 시간당 한도가 있습니다. 이 앱은 한도가 없는 "보기 모드"로 먼저 조회하고, 한 번 연 표는 기억해서 다시 조회하지 않습니다. 한도 오류가 나면 60분 안에 다시 채워집니다.

**"저장 실패"가 떠요.**
위에 마우스를 올리면 나오는 문구를 확인하세요. 도구 권한이 빠졌거나, Notion 접근 허용이 풀렸을 수 있습니다.

**"이 화면에서는 Notion에 연결할 수 없어요"가 떠요.**
claude.ai에 로그인한 상태에서 연 것인지, Notion 커넥터가 연결되어 있는지 확인하세요. HTML 파일을 그냥 열었거나 다른 곳에 올린 경우에도 이 문구가 뜹니다. 꼭 아티팩트로 게시해서 쓰세요.

**한글 CSV를 가져왔더니 글자가 깨져요.**
UTF-8과 Excel 기본 CSV 인코딩은 자동으로 구분합니다. 그래도 깨지면 Excel에서 `.xlsx`로 저장해서 가져오세요.

## 알아둘 점과 한계

- 한 번에 가져오는 행은 **최대 500행**입니다. 중간에 오류가 나면 이미 추가된 행은 남으므로, 같은 파일을 다시 가져오면 중복됩니다.
- 보기에 날짜 필터 같은 조건이 걸려 있으면, 가져온 행이 Notion에는 들어갔어도 표에는 안 보일 수 있습니다.
- 한 번에 불러오는 행은 100행입니다. 더 있으면 `모두 불러오기`를 누르세요(약 1,000행까지).
- 사람·수식·롤업 열은 보기만 되고 편집·가져오기는 되지 않습니다. 상태 열은 기존 선택지 중에서만 고를 수 있습니다.
- 데이터베이스 자체를 지우는 기능과, 열 순서·필터를 Notion 보기에 되돌려 저장하는 기능은 없습니다.
- Excel 파일 처리를 위해 필요할 때만 cdnjs의 [SheetJS](https://sheetjs.com/)를 불러옵니다.
- Notion 커넥터의 도구 이름과 입력 형식이 바뀌면 일부 기능이 동작하지 않을 수 있습니다.

## 개인정보와 보안

- 이 앱에는 **로그인 정보, 토큰, 개인 데이터가 들어 있지 않습니다.** 파일은 누구나 열어 볼 수 있는 코드입니다.
- 앱이 읽고 쓰는 Notion 데이터는 **여는 사람 본인의 claude.ai 계정**과 Notion 커넥터를 통해서만 오갑니다. 이 프로젝트의 제작자는 그 데이터를 볼 수 없습니다.
- 앱이 보관하는 설정(고정, 열 순서, 필터 등)은 **내 브라우저에만** 저장됩니다.
- 파일을 내려받아 게시하기 전에, 코드를 직접 읽어 보거나 Claude에게 "이 파일이 Notion 외에 어디로 데이터를 보내는지 점검해줘"라고 확인해 보시길 권합니다.
